🍕 Pizza Sales Analysis
This project involves analyzing pizza sales data using SQL and presenting key insights in a visual format using Canva. The dataset includes information about pizzas, pizza types, orders, and order details.

📊 Project Overview
The primary objective of this project is to extract meaningful business insights from a pizza store's historical sales data to help make data-driven decisions. The analysis was done using SQL queries on a relational database, and the results were visualized using Canva for presentation purposes.

📁 Dataset Details
The dataset contains the following tables:

pizzas.csv: Contains pizza IDs, sizes, and prices.

pizza_types.csv: Contains names, categories, and ingredients of different pizza types.

orders.csv: Includes order IDs and order dates.

order_details.csv: Contains detailed information on each item in an order (pizza type and quantity).

🛠️ Tools Used
SQL: For querying and data analysis.

Canva: For creating the final presentation and data visualizations.
